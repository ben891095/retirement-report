# 退休試算

一個沒有框架、沒有建置步驟、沒有第三方依賴的單頁靜態網站。輸入現有的現金與投資、每月開銷與負債，算出逐年／逐月的資產變化。

## 用法

1. 填入以下欄位（開頁時全部為空，輸入後即時重算）：

   | 區塊 | 欄位 | 說明 |
   |---|---|---|
   | 基本 | 還要活多久（年） | 試算期間，1 以上的整數 |
   | 基本 | 現金 | 每月支出會先動用這裡 |
   | 收入 | 投資金額 | 投資部位本金 |
   | 收入 | 預期年報酬率（%） | 投資的年化報酬 |
   | 支出 → 一般 | 每月開銷 | 生活支出，固定支出＋非固定支出的大約金額 |
   | 支出 → 負債 | 每月還款額、剩餘月份 | 可多筆，每筆一列；沒有負債就留空 |

2. **試算結論**告訴你撐不撐得過、要撐滿需把月開銷降到多少、現金什麼時候用完，並**逐筆列出每一筆負債在第幾年第幾月付清**。
3. **資產走勢**有三條線：現金、投資金額、負債（剩餘還款總額）。
4. **逐年／逐月報表**預設以年為單位摺疊，點年列可展開該年的 12 個月；年列上會直接標示該年有哪筆負債結清。

## 本機執行

模組以 ESM 載入，**不能直接用 `file://` 開啟**，需要起一個靜態伺服器：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000。

沒有安裝 Python 時，Windows 可以用內建的 PowerShell 起一個臨時伺服器：

```bash
powershell -NoProfile -Command "$l=New-Object Net.HttpListener;$l.Prefixes.Add('http://localhost:8000/');$l.Start();while($l.IsListening){$c=$l.GetContext();$p=Join-Path (Get-Location) ($c.Request.Url.AbsolutePath.TrimStart('/'));if($c.Request.Url.AbsolutePath -eq '/'){$p=Join-Path (Get-Location) 'index.html'};if(Test-Path -LiteralPath $p -PathType Leaf){$b=[IO.File]::ReadAllBytes($p);$e=[IO.Path]::GetExtension($p);$c.Response.ContentType=@{'.html'='text/html; charset=utf-8';'.css'='text/css; charset=utf-8';'.js'='text/javascript; charset=utf-8'}[$e];$c.Response.OutputStream.Write($b,0,$b.Length)}else{$c.Response.StatusCode=404};$c.Response.OutputStream.Close()}"
```

## 計算模型

每個月依序做這幾件事：

1. **投資報酬** ＝ 上月月末投資金額 × (年報酬率 / 12)，**存入現金**。
2. **支出** ＝ 生活支出 ＋ 當月所有「剩餘月份 > 0」的負債月付加總。
3. 現金 ＝ 上月現金 ＋ 投資報酬 － 支出。
4. 現金不夠時，**先提領投資**補足（投資最低到 0）；提領後仍不夠，現金就轉為負值。
5. 每筆負債的剩餘月份減 1；歸 0 的那個月即結清，**次月起**不再扣該筆月付。

所有金額每月各自四捨五入至整數元。

提領投資會讓本金變小，**下個月的投資報酬也跟著變小**——這個連動有算進去。

**現金耗盡 ≠ 資產用完**：現金歸零後還能靠提領投資撐下去，兩者是不同的時間點，結論卡會分別說明。

**最高可支撐月開銷**：在其他輸入不變的前提下，讓期末總資產仍 ≥ 0 的最大每月開銷。若連完全不花錢都撐不過（缺口來自既有債務還款），結論卡會直接說明，不顯示開銷上限。

## 模型假設與已知簡化

這些是刻意的設計，不是 bug：

- **投資報酬不滾入本金（不複利）**——報酬存進現金，投資本金除非被提領否則維持不變。
- **負債不計利息**——只用「每月還款額 × 剩餘月份」描述，不含本金攤還或利率。
- **資產可以為負，且資金缺口不滾利息**——資產用完後繼續累積缺口，但不對缺口計算任何借貸成本。
- **月報酬率採「年報酬率 / 12」的單利折算**，略高於幾何折算的年化報酬。

另外也未納入：

- **固定名目支出、不計通膨**——月開銷在整段期間維持不變，不隨物價上升。
- **固定報酬假設**——不模擬波動、順序報酬風險或市場下跌。
- **未計稅負**（資本利得、股利、所得稅皆未計算）。
- **未計其他退休收入**（勞保年金、租金等）。
- 不含一次性大額事件（換車、醫療、房屋修繕等）。
- 現金與投資金額只涵蓋你輸入的部位，**不包含房屋、不動產或其他未輸入的資產**。

請注意這些簡化的方向並不一致：**「不複利」會讓結果偏保守，「缺口不滾利」與「不計通膨」則會讓結果偏樂觀**，兩者互相抵銷的程度無法預先得知。

## 免責聲明

本工具僅供情境試算，**不構成財務建議**。實際結果會受到通膨、市場波動、稅負、健康狀況與收入變化影響。重大財務決策請諮詢合格的專業人士。

## 檔案結構

```
index.html      單頁：輸入表單 + 結論卡 + 圖 + 報表
css/style.css   固定暗色主題
js/calc.js      純計算，不碰 DOM
js/chart.js     手繪 SVG 折線圖
js/money.js     金額格式化 / 解析
js/ui.js        讀表單、渲染、事件綁定（進入點）
PLAN.md         完整規格：計算模型、UI 行為、視覺規格、驗證測例
```

沒有 `package.json`、沒有相依套件、沒有建置步驟。改完存檔重新整理即可。

**要重做或大幅修改時請先看 [PLAN.md](PLAN.md)**——裡面記錄了計算模型的核心假設、色票與版面規格，以及一組可手算對照的黃金測例。
