# 退休試算

純 HTML、CSS 與 JavaScript 製作的退休資金試算網站，無框架、第三方依賴或建置步驟。

輸入現金、投資金額、每月開銷及負債後，可查看：

- 資金是否足以支撐整段試算期間
- 現金與總資產的耗盡時間
- 可支撐的最高月開銷
- 各筆負債的付清時間
- 資產走勢及逐年／逐月明細

## 使用方式

填入以下資料後，網站會自動重新計算：

| 區塊 | 欄位 | 說明 |
|---|---|---|
| 基本 | 還要活多久（年） | 試算期間，須為大於或等於 1 的整數 |
| 基本 | 現金 | 支出會優先從現金扣除 |
| 收入 | 投資金額 | 產生報酬的投資本金 |
| 收入 | 預期年報酬率（%） | 投資的預期年報酬率 |
| 支出／一般 | 每月開銷 | 每月固定及非固定生活支出估計 |
| 支出／負債 | 每月還款額、剩餘月份 | 可新增多筆；沒有負債時保持空白 |

試算結果分為三部分：

1. **試算結論**：顯示資金是否足夠、資產耗盡時間、最高月開銷及負債付清時程。
2. **資產走勢**：顯示現金、投資金額及剩餘負債的變化。
3. **逐年／逐月報表**：年列預設收合，可展開查看每月明細。

## 本機執行

網站使用 JavaScript ES Modules，不能直接透過 `file://` 開啟。請在專案目錄啟動靜態伺服器：

**要先安裝 python**

```bash
python -m http.server 8000
```

接著開啟 [http://localhost:8000](http://localhost:8000)。

## 部署至 GitHub Pages

1. 將專案推送至 GitHub repository 的 `main` 分支。
2. 前往 **Settings → Pages**。
3. Source 選擇 `main` 分支及 `/ (root)`。
4. 開啟 `https://<user>.github.io/<repo>/`。

專案已包含 `.nojekyll`，GitHub Pages 不會使用 Jekyll 處理網站內容。

## 計算方式

每月依下列順序計算：

1. 投資報酬 = 上月期末投資金額 ×（年報酬率 ÷ 12），報酬存入現金。
2. 當月支出 = 每月開銷 + 所有有效負債的月付合計。
3. 現金不足時，提領投資補足；投資最低為 0。
4. 投資仍不足時，現金轉為負值並持續累積資金缺口。
5. 各筆負債扣款後，剩餘月份減 1；歸零當月視為結清，次月停止扣款。

每月金額各自四捨五入至整數元。提領投資會降低本金，因此下個月的投資報酬也會下降。

現金耗盡不等於總資產耗盡：現金不足後仍可提領投資，兩個時間點會分別顯示。

「最高可支撐月開銷」是指其他條件不變時，期末總資產仍大於或等於 0 的最大月開銷。若月開銷為 0 仍不足，系統會說明缺口來自既有負債。

## 模型假設與限制

- 投資報酬存入現金，不加入投資本金，因此不計複利。
- 月報酬率以「年報酬率 ÷ 12」計算。
- 投資報酬率固定，不模擬市場波動或順序報酬風險。
- 負債不計利息，只依每月還款額及剩餘月份計算。
- 資金缺口不計利息或借貸成本。
- 每月開銷固定，不計通膨。
- 不計稅負、退休後收入及一次性大額收支。
- 資產只包含輸入的現金與投資，不包含房屋或其他未輸入資產。

上述假設可能使結果偏保守或偏樂觀，試算結果僅適合用來比較不同情境。

## 專案結構

```text
index.html       頁面結構與輸入表單
css/style.css    暗色主題與響應式版面
js/calc.js       試算邏輯
js/chart.js      SVG 資產走勢圖
js/money.js      金額解析與格式化
js/ui.js         畫面渲染與事件處理
PLAN.md      整理後的完整規格
```

修改檔案後重新整理頁面即可，不需要安裝套件或執行建置。
